Recovery Token Fix - 2026-08-28

1. /api/admin/tokens now verifies persistent cloud storage writes before reporting success.
2. /api/admin/tokens/bulk generates the requested batch server-side in one read/write cycle and returns only persisted tokens.
3. Token generation uses crypto.randomInt and collision checks.
4. Desktop SSAPP keys now authenticate through /api/desktop/activate in the Python client.
5. Desktop admin keys receive an admin session cookie so the desktop Admin Panel can call admin APIs.
6. Desktop admin-key creation reports persistence failures instead of false success.
7. Bulk generation in the web UI uses the server-side bulk endpoint instead of firing one request per token.
