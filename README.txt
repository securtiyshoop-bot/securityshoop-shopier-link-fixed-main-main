SecurityShoop Public + Admin

Bu sürümde:
- Site herkese açık
- Ziyaretçiler login olmadan siteyi görebilir
- Login/Register isteğe bağlı modal olarak açılır
- Sadece admin hesabıyla giriş yapan kişi admin paneli görür
- Kullanıcılar admin panelini göremez

Kurulum:
1) .env.example dosyasını .env yap
2) MySQL bilgilerini doldur
3) Admin bilgilerini doldur
4) npm install
5) npm start
